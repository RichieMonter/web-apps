web-apps:
Framework: Estructura de trabajo reutilizable que dicta la arquitectura de una aplicación (Ejemplos: React, Spring Boot, Django).



Librería: Conjunto de código o funciones auxiliares que el desarrollador invoca según su necesidad (Ejemplos: Lodash, Axios, Pandas).



Package Management System: Herramienta para instalar, actualizar y administrar dependencias de un proyecto (Ejemplos: npm, pip, Maven).



Git y Comandos: Control de versiones distribuido. Comandos clave: git init, git clone, git status, git add, git commit, git push, git pull, git checkout.



GitHub, Pull Request y Merge: GitHub es una plataforma en la nube para alojar repositorios Git. Un Pull Request (PR) es una solicitud para integrar cambios de una rama a otra. El Merge es la acción de fusionar esas ramas.
Local vs Prod Environment: Local es el entorno de desarrollo en la máquina del programador; Prod (Producción) es el servidor en vivo accesible para los usuarios finales.



Web Server: Software que procesa solicitudes HTTP y sirve archivos web (Ejemplos: Nginx, Apache, IIS).



Database Manager (DBMS): Sistema para almacenar, administrar y consultar datos organizados (Ejemplos: PostgreSQL, MySQL, MongoDB).



Runtime / Interpreter: Entorno o programa que ejecuta el código fuente directamente (Ejemplos: Node.js, Python CPython, JVM).



IDE: Entorno de desarrollo integrado con herramientas como editor, depurador y terminal (Ejemplos: VS Code, IntelliJ IDEA, PyCharm).
