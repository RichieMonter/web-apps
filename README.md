web-apps:
Local vs Prod Environment: Local es el entorno de desarrollo en la máquina del programador; Prod (Producción) es el servidor en vivo accesible para los usuarios finales.



Web Server: Software que procesa solicitudes HTTP y sirve archivos web (Ejemplos: Nginx, Apache, IIS).



Database Manager (DBMS): Sistema para almacenar, administrar y consultar datos organizados (Ejemplos: PostgreSQL, MySQL, MongoDB).



Runtime / Interpreter: Entorno o programa que ejecuta el código fuente directamente (Ejemplos: Node.js, Python CPython, JVM).



IDE: Entorno de desarrollo integrado con herramientas como editor, depurador y terminal (Ejemplos: VS Code, IntelliJ IDEA, PyCharm).
